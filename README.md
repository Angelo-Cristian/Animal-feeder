# 🎮 Animal Feeder
This is a game made in Unity in which you have to shoot sandwiches at animals that are rushing towards you to feed them and make them disappear.
<img width="1910" height="862" alt="Animal feeder" src="https://github.com/user-attachments/assets/b3b33f87-c0d9-44cb-89ae-eb96e7c7bc1f" />

---

## 🛠️ Technical details
* **Movement system** -> Built using Unity's Input Manager to handle the horizontal movement for the player (farmer).
* **Spawn system** -> Different types of animals are spawned randomly at intervals outside the top boundary of the screen.
* **Shooting system** -> Allows the player to launch projectiles (sandwiches) to feed the incoming animals before they cross the bottom line.
* ⚠️ *Note: I do not own the art/UI assets used in this project.*
