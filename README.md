# 🎮 Animal feeder
This is a game made in unity in witch you have to shoot sandwiches at animals that are rushing towards you to make them disappear.
<img width="1910" height="862" alt="Animal feeder" src="https://github.com/user-attachments/assets/b3b33f87-c0d9-44cb-89ae-eb96e7c7bc1f" />


## 🛠️ Technical details
* **Movement system** -> I used the input manager to create the movement for the farmer(player)
* **Spawn system** -> the animals are spawned randomly
* **Shooting system** -> to defend yourself from the animals that are rushing towards you
* !! The assets are not mine.
